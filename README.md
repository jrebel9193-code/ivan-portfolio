# Иван Чернявский — портфолио

Версия сайта для размещения в Timeweb Cloud. В проект входят публичное портфолио и закрытая админка по адресу `/admin`.

## Что можно менять в админке

- фотографии, разделы, подписи и порядок работ;
- все основные тексты сайта, включая блок «ПОДХОД»;
- Telegram, VK и телефон.

## Переменные окружения

Скопируйте список из `.env.example` в настройки приложения Timeweb Cloud. Настоящие пароли и ключи нельзя добавлять в GitHub.

## Запуск

```bash
npm ci
npm run build
npm run start
```

Приложение автоматически создаёт необходимые таблицы в PostgreSQL при первом открытии. Новые фотографии из админки сохраняются в S3-хранилище.
